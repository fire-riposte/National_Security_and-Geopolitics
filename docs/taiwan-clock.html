SEC_06 // METHOD

How the clock is set

Each dial is scored from −2 (strong reason to wait) to +2 (strong reason to act soon). Each indications and warning (I&W) indicator is scored 0 to 3. Dials are weighted equally, as in Moore.

  • S = (mean dial reading + 2) / 4 motive, 0 to 1
  • T = mean I&W level / 3 preparation, 0 to 1
  • minutes = round(60 − 30·S − 28·T) clamped to 2 to 60
  • if any I&W level is 3: minutes ≤ 10

Motive alone can take the clock to 30 minutes. Getting inside that takes preparation you can see. The split is deliberate: Moore's own reading in 2025 had {% if moore_ref %}{{ moore_ref.sooner | escape }} of {{ dial_total }}{% else %}most{% endif %} dials favoring action, and nothing happened, because motive is not intent.
